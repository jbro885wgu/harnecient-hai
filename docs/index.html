hai

A small, private chat that learns from what you teach it. No language model: it follows rules and counts. This demo runs the same rules as the command line.

state=start name=
Install (planned)

The installer is a stub right now. The real one is a milestone not yet built, so this command installs nothing yet:

curl -fsSL https://raw.githubusercontent.com/jbro885wgu/harnecient-hai/hai/install.sh | sh -s -- hai

To try it today, clone the repo and follow book/04-hai-model/1.hai-user-tutorial.md.

What this demo can not do (the full app can)
  • Typing in a window, and a real desktop window: the full app.
  • Linking your own documents so it learns them at once: the full app (design stage).
  • Watching other models and learning from them: the full app (design stage).
  • Tool calls (open a page, list pages): the full app (milestone M4).
  • Learning here is only the grade counts. It never rewrites its replies.
  • Your account and ledger stay in this browser only. The full app keeps them on your machine.

If one of these blocks you, say so: that limit is a desk to fix, not a reason to stop.

How this works

Every message adds a row (a TURN) to a ledger kept in this browser. The state and your name are rebuilt from those rows each time, so a reload keeps the chat where it was.

Learning from your grades (0 to 4) and from linked documents is not built yet, so this demo does not get better yet.
