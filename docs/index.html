hai

A small, private chat that learns from what you teach it. No language model: it follows rules and counts. This demo runs the same rules as the command line.

state=start name=
Install it on your computer

Linux or macOS, a terminal, and a C compiler (cc, gcc or clang). No sudo, no language model, nothing leaves your machine:

curl -fsSL https://raw.githubusercontent.com/jbro885wgu/harnecient-hai/hai/install.sh | sh -s -- hai

It builds into ~/.local/share/hai, writes the hai command to ~/.local/bin and keeps your chat ledger in ~/.local/share/hai-chat (an update never touches it). Then type hai. Remove it with sh install.sh uninstall.

The command line has the same levers as this page (/teach, /alias, /say, /mark, /pack, /bank, /why).

      How this works
      
Every message adds a row (a TURN) to a ledger kept in this browser. The state and your name are rebuilt from those rows each time, so a reload keeps the chat where it was.

      
Type a word hai does not know and it asks what it means, then remembers your answer. Teach more with /teach word = meaning, /alias word = concept, /say word = text; mark a word that matters with /mark word; grade the last reply with /grade 0 to /grade 4 (or the buttons). The gray line under each answer says why it answered that way.

      
Same rules as the command line: the case hai_web_parity runs the C engine and this one on the same conversation and requires identical output.
